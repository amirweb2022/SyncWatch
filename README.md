# SyncWatch

A free, ephemeral watch party for sharing a screen with one other person.

## Setup

1. Install Node.js 20.9 or newer.
2. Copy `.env.example` to `.env.local` and set the Supabase project URL and anon key. TURN values are optional.
3. Install dependencies with `npm install`.
4. Start the app with `npm run dev` and open the displayed local URL.

This scaffold contains no authentication or database setup. See `PRD.md` for product requirements and `AGENTS.md` for development rules.
